# devuan scripts

These are assorted scripts i use on devuan, the scripts span the following cathegories:

| Cathegory | Comments |
| :--  | :--      |
| [apt](scripts/apt) | Scripts for apt and package management. |
| [cronjobs](scripts/cronjobs) | Scripts for cronjobs. |
| [installer-scripts](scripts/installer-scripts) | Scripts to install packages not in debian/devuan |
| [tweaks](scripts/tweaks) | Scripts to tweak system settings |
| [wrappers](scripts/wrappers) | Scripts to wrap some commands. |
